GOOG・NVDA Stop設計研究 v1.2.0

目的:
価格構造Stopを基本にしつつ、異常に小さい1Rを防ぐ研究仮説
「価格構造＋最低ATR×1」を追加し、既存4方式と同じ条件で比較します。

新方式:
Stop = min(価格構造Stop, Entry - シグナル日ATR14)
つまり 1R幅 = max(価格構造1R幅, ATR14)

重要:
- 既存v5.3は変更しません。
- 新方式は研究候補であり正式採用ではありません。
- 比較は5方式すべて設計可能な共通イベント母集団で行います。
- 前5年で選択し、現5年で固定確認します。
- 手数料、Slippage、Gap Open、同日Stop+Target順序不明処理を維持します。
